# 🏙️ Civic Issue Tracker

**Civic Issue Tracker** is a web application designed to empower citizens to report, track, and resolve local civic issues (like potholes, garbage dumps, or broken streetlights) effectively.

## 🚀 Project Overview
This project aims to bridge the gap between citizens and municipal authorities by providing a transparent and easy-to-use platform for grievance redressal.

### ✨ Key Features
- **User-Friendly Interface:** Clean and responsive UI built with React.
- **Issue Reporting:** Users can easily submit complaints.
- **Real-time Tracking:** (Planned) Monitor the status of reported issues.
- **Fast Performance:** Powered by Vite.

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite
- **Styling:** CSS
- **Package Manager:** NPM

## ⚙️ How to Run Locally

Follow these steps to run the project on your computer:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Poojaagadhe/hackthonkne-2.git](https://github.com/Poojaagadhe/hackthonkne-2.git)

2. Navigate to the project directory:
   - cd hackthonkne-2

3. Install dependencies:
    - npm install

4. Start the development server:
    - npm run dev

5. Open the link shown in the terminal (usually http://localhost:5173) to view the app.
